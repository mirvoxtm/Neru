# Neru
Neru is an implementation of my first interpreted language, Tetolang - made fully in my Interpreted Programming Language: Bern.

This is only a study project and i'll finish it up over time. Mostly - this is a test of the Bernparsec library and if the makings of a Interpreted Language in Bern is viable.

---
### Implemented Functionalities:
[x] Abstract Syntax Tree
[x] Parser
[-] Evaluator
[x] Basic Arithmetic
[x] Booleans
[x] REPL
[x] Eq
[x] Conditionals
[] Variables
[] Array Related Stuff
